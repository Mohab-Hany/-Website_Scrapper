# Website Scrapper 🕷️

تطبيق بايثون بيعمل Scrape لمواقع الويب ويستخرج البيانات منها تلقائيا.

## 📌 المميزات
- استخراج البيانات من المواقع باستخدام `BeautifulSoup` و `Requests`
- حفظ النتائج في ملف CSV او طباعتها في التيرمنال
- التعامل مع اكتر من صفحة / Pagination
- كود منظم وسهل التعديل

## 🛠️ المتطلبات
- Python 3
- مكتبات: `requests` `beautifulsoup4` `lxml`
```bash
pip install requests beautifulsoup4 lxml
